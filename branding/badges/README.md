# Store badges

The official badges of the three stores S.P.R.U.C.E+ is published in, used in the main README. They
are the stores' own artwork, unchanged, and follow each store's rules: every badge is a link to the
extension's listing in that store, is shown at the same height as the others (60 pixels in the README),
and has space around it.

| File | Store | Source and rules |
|---|---|---|
| `microsoft-edge-add-ons.png` | [Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/spruce/ailfmflfcombomabeallgefjkkejjijh) | The English badge from Microsoft's [badge image files](https://raw.githubusercontent.com/microsoft/MicrosoftEdge-Extensions/refs/heads/main/assets/Microsoft_Edge_Add-ons_badge_image_files.zip); [guidelines](https://learn.microsoft.com/en-us/microsoft-edge/extensions/publish/add-ons-badge): don't modify it in any way, keep the gray border, always a clickable link to the listing, at least 32 pixels high, clear space of a quarter of its height around it, and among other store badges the same size or larger |
| `chrome-web-store.png` | [Chrome Web Store](https://chromewebstore.google.com/detail/spruce+/ennpekfncgndmiffefhbkpdnjnnnhcpc) | The medium badge with border from Google's [branding guidelines](https://developer.chrome.com/docs/webstore/branding): link it to the listing, don't modify it other than resizing (keep its proportions), keep it legible and apart from other logos, and don't make it the main element of the page |
| `firefox-add-ons.png` | [Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/s-p-r-u-c-e/) | The 172×60 "Get the add-on" badge from Mozilla's [promoting your extension](https://extensionworkshop.com/documentation/publish/promoting-your-extension/) page: link it to the listing |

In text, the stores are always named in full: "Microsoft Edge Add-ons", "Chrome Web Store", "Firefox
Add-ons" (addons.mozilla.org).
