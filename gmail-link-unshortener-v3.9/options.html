Architecture & Zero-Touch Threat Protection

This extension scans all links safely, using specialized techniques to guarantee single-use tokens (like password resets) are never accidentally consumed:

  • Token Heuristics: Paths containing `/reset` or query params with `token=` are flagged immediately. Background HTTP tracing is skipped for these to preserve the token.
  • Smart Halting: For single-use tokens wrapped in trackers (e.g. Sendgrid), the extension uses redirect: 'manual' to halt the request instantly before the destination token is consumed.
  • Zero-Touch Threat Intel: Threat evaluation happens strictly via DoH APIs. The destination web server is never pinged directly.
